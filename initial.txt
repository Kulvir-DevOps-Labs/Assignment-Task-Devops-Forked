GitHub is a cloud-based hosting service for software development and version control using Git. Here are the core features grouped by functionality:


##################################
Version Control & Collaboration
##################################

• Repositories (Repos): Digital storage folders for your project's files, commit history, and revision tracking.
• Pull Requests (PRs): Proposed code updates that developers submit to the team for discussion, review, and approval before merging.
• Branching: Isolated environments that let you safely work on new features or bug fixes without breaking the main codebase.
• Forking: Copying another developer's repository to your own account so you can freely experiment without changing the original project.
